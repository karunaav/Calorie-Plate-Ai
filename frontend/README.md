
# Frontend – DeepSeek Calorie Vision

Vite + React single-page app that talks to the FastAPI backend.

## Setup

1. Install dependencies:

   ```bash
   cd frontend
   npm install
   ```

2. Start the dev server:

   ```bash
   npm run dev
   ```

   By default this runs on `http://localhost:5173`.

3. Make sure the Python backend is running on `http://localhost:8000`.

4. Open the frontend in your browser, upload a meal photo, optionally describe it,
   and view the DeepSeek-powered calorie estimate.
